# Code of Conduct

LocalPilot adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone participating in the project's spaces: issues, pull requests, discussions and any other project channel.

In short: be respectful and constructive, assume good intent, welcome newcomers, and focus on what is best for the project and its users. Harassment, personal attacks and discriminatory language are not tolerated.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainers. Open a [private report](https://github.com/pcittadini/localpilot/security/advisories/new) titled "Code of Conduct report". Reports are handled confidentially.

Maintainers enforce this code following the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban), in proportion to the behaviour.
